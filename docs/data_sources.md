# Trusted Data Sources Mapping

Every indicator in the dashboard is mapped to an official international reporting organization.

## Trusted Organizations & Data Portals

| Organization | Primary Indices Tracked | URL |
| :--- | :--- | :--- |
| **World Bank** | GDP, GDP per Capita, LPI, Ease of Doing Business, GovTech | [data.worldbank.org](https://data.worldbank.org) |
| **IMF** | GDP PPP, GDP Growth Rate, Inflation, Public Debt | [imf.org/en/Data](https://www.imf.org/en/Data) |
| **United Nations / UNDP** | HDI, World Happiness Report, SDG Score, GII | [hdr.undp.org](https://hdr.undp.org) |
| **World Health Organization (WHO)** | Health Index, Universal Coverage, Life Expectancy, Infant Mortality | [who.int/data](https://www.who.int/data) |
| **UNESCO** | Education Index, Literacy Rate, School Enrollment | [uis.unesco.org](https://uis.unesco.org) |
| **World Economic Forum (WEF)** | Global Competitiveness Index, Global Gender Gap | [weforum.org](https://www.weforum.org) |
| **Transparency International** | Corruption Perceptions Index (CPI) | [transparency.org](https://www.transparency.org) |
| **Reporters Without Borders** | Press Freedom Index | [rsf.org](https://rsf.org) |
| **Oxford Insights** | Government AI Readiness Index | [oxfordinsights.com](https://oxfordinsights.com) |
| **World Justice Project** | Rule of Law Index | [worldjusticeproject.org](https://worldjusticeproject.org) |
| **ITU** | Global Cybersecurity Index, ICT Development | [itu.int](https://www.itu.int) |
| **WIPO** | Global Innovation Index, R&D Expenditures, Patents | [wipo.int/gii](https://www.wipo.int/gii) |
| **StartupBlink** | Startup Ecosystem Ranking | [startupblink.com](https://www.startupblink.com) |
| **Yale EPI** | Environmental Performance Index | [epi.yale.edu](https://epi.yale.edu) |
| **Germanwatch** | Climate Change Performance Index | [germanwatch.org](https://www.germanwatch.org) |
| **IQAir** | Air Quality Ranking | [iqair.com](https://www.iqair.com) |
| **Numbeo** | Quality of Life, Cost of Living, Crime & Safety Index | [numbeo.com](https://www.numbeo.com) |
| **Our World In Data** | CO2 Emissions, Renewable Share, Democracy Index | [ourworldindata.org](https://ourworldindata.org) |
| **UN DESA** | E-Government Development Index, E-Participation Index | [publicadministration.un.org](https://publicadministration.un.org/egovkb) |
